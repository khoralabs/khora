# @khoralabs/vellum-cli

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run src/index.ts
```

Account removal on the Atrium host (when supported) is done via the Atrium CLI / client (`atrium unregister --yes`); see `apps/atrium/README.md` and `apps/vellum/README.md` for what is and is not deleted.

This project was created using `bun init` in bun v1.3.4. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
