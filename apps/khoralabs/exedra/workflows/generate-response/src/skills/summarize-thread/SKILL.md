# Summarize Thread

Produce a concise summary grounded in the provided messages and available memories.

Prefer decisions, open questions, unresolved risks, and useful context over a chronological transcript. Do not invent conclusions or memory details.

If evidence is thin, say so briefly and summarize only what is supported.
